# missUmovie Backend Service

Modular Node.js Express REST API for the missUmovie streaming application.

## Technologies

- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB & Mongoose
- **Authentication**: JSON Web Tokens (JWT) & bcryptjs
- **File Uploads**: Multer

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server (requires nodemon):
   ```bash
   npm run dev
   ```

3. Start production server:
   ```bash
   npm start
   ```
