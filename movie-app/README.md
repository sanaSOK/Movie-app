# missUmovie Frontend Application

A beautiful, modern React application for streaming movies, dramas, and anime built with Vite, React Router, and Lucide React.

## Folder Structure

```
movie-app/
│
├── public/
│   ├── images/
│   ├── icons/
│   └── favicon.ico
│
├── src/
│   ├── assets/
│   │   ├── images/
│   │   ├── icons/
│   │   └── styles/
│   │
│   ├── components/
│   │   ├── Navbar/
│   │   ├── Footer/
│   │   ├── MovieCard/
│   │   ├── SearchBar/
│   │   ├── Loading/
│   │   └── Pagination/
│   │
│   ├── pages/
│   │   ├── Home.jsx
│   │   ├── MovieDetail.jsx
│   │   ├── Favorite.jsx
│   │   ├── Search.jsx
│   │   └── NotFound.jsx
...
```

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```
